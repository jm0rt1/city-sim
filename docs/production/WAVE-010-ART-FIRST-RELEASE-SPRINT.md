## Fast batch cadence

1. **Source freeze:** World Art returns one clean exact family candidate,
   immutable hashes, provenance, registration, color/grayscale actual-scale
   sheets, and an independent source disposition. A direction covered by
   CONTRACT-018 uses its exact frozen raw master instead of rerendering; all
   downstream normalization and packing remain deterministic.
2. **Ingestion window:** World Rendering synchronizes to the current published
   master, ingests only the accepted family, runs focused pack/runtime tests,
   builds once, and returns one clean candidate.
3. **Integration gate:** Integration reviews the exact range, runs one full
   native suite, one staged verification, and one isolated renderer/resource
   budget check. Worker lanes do not duplicate the complete integration suite.
4. **Focused real-app gate:** PLAY-075 operates the exact staged candidate once
   at regular and exact 900 x 600 sizes. It checks the upgraded Industrial lot,
   N/E/S/W frontage matrix, city/neighborhood/block LOD, pointer and keyboard
   selection, construction/condition, Undo, Reduce Motion, AX identity, and
   visible comparison to the previously published level.
5. **Publish or return:** Integration either publishes the exact batch or
   returns it with a candidate-bound defect. The next reserved window begins
   only after that disposition.

This cadence removes repeated full-suite and duplicated staged-journey waits;
it does not weaken exact baseline/candidate identity, build/resource parity,
shared-contract ownership, performance limits, or independent QA.

## Stop conditions

Stop a batch on stale or dirty authority, a second writer on renderer/shipping
surfaces, unreviewed source pixels, alias/mirror/rotation/fallback, source-pack
hash drift, frontage/registration failure, mixed-fidelity regression, compact
or LOD loss, interaction/Undo/accessibility regression, resource-budget
failure, candidate substitution, or an attempt to self-accept.
