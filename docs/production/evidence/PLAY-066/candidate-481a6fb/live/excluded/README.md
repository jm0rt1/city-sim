# Excluded live captures

Nothing in this directory is binding comparison or LOD evidence.

The initial regular capture used a stale Day-51 state and a materially
different camera from the accepted Day-53 baseline. Later shortcut experiments
exercised `0`, `-`, `=`, keypad add, and scroll routes while diagnosing
map-focus delivery, but filenames did not prove the resolved visual detail.
Some files were overwritten during that diagnosis and therefore cannot
represent an immutable same-state series.

They are retained to disclose the failed route rather than silently discarded.
The only binding live evidence is under `../accepted/`, where every LOD is
captured from a separate exact process with an explicit accepted camera scale,
Day 53 paused truth, and Industrial block `15,12` selection in the AX tree.
