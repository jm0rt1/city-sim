# CitySim World Art Pipeline

The shipping `WorldAssets.atlas` is original, repo-owned artwork generated by
`generate_world_assets.py`. It uses only deterministic vector/raster drawing
instructions in this repository; no external image, stock pack, game asset, or
model-generated pixel is sampled into the atlas.

## Authoring and provenance

- Authoring method: Pillow polygons, lines, seeded texture marks, and blur passes.
- Projection: 2:1 isometric, authored at 2× (`144 × 72` terrain/road tiles).
- Light: warm northwest key; cast shadows fall southeast.
- Filtering: bilinear (`SKTexture.filteringMode = .linear`).
- License: original project artwork, copyright JFM Systems; repository use only.
- Stable identity: asset names plus `WorldVisualSeed`, independent of simulation seed.

The model-generated `docs/production/evidence/PLAY-021/art-direction-reference.png`
is a disclosed mood/composition reference only. Its pixels are not used here.

## Rebuild

Use the Codex bundled Python runtime so Pillow is available:

```bash
/Users/James/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  Native/CitySimNative/WorldArt/generate_world_assets.py
```

The generator replaces only named files inside
`Sources/CitySimNative/Resources/WorldAssets.atlas` and writes a manifest with
the palette, scale, filtering, provenance, and SHA-256 digest for each asset.
